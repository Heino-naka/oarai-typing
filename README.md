# 大洗町タイピング探検

大洗町のこどもたちが、自分の町のことばをローマ字で打って遊びながら「ふるさとカード」を集める、無料のタイピングゲームです。

- 遊び方：コースを選び、60秒でできるだけ多くの言葉を打ちます。得点でしらす（コイン）がたまり、ガチャでカードが出ます。
- 言葉：町名・神磯の鳥居・大洗海岸・アクアワールドのサメ・しらすなど約300語（カード189枚）。
- ねらい：画面の中で終わらず、本物の大洗の町へ出かけたくなること。
- 対象：小学生（学校のChromebook・パソコン／キーボード入力前提）。登録不要。
- 作り：単一のHTMLファイルで動作し、外部サービスへの通信はありません。記録は端末のブラウザ内だけに保存されます。
- 姉妹版：「いばらきタイピング探検MAP」から、ほかの市町村版も遊べます。
